# middleManPS4 v0.12.0 — Offline Reverse Engineering Toolkit

**Scope:** read-only reverse engineering of local, legitimately obtained files and previously sanitized network summaries. **No PSN access, no firmware spoofing, no online authentication, no active traffic modification.** All commands below run locally and require only Python 3.11+.

## Components

| Module | Purpose | Important limitation |
|---|---|---|
| `rekit.binary` | Classify ELF64 x86-64, Orbis ELF e_types, identify PS4 SELF containers, enumerate ELF program headers | SELF identification is **not** decryption. A compatible header does not imply a loadable PS4 payload. |
| `rekit.psf` | Parse **raw** `PARAM.SFO` / PSF 1.0/1.1 into typed JSON, including UTF-8, integers and bounded binary previews | Does not parse a PSAR wrapper, does not rewrite SFO. Some PSF values are app metadata, **not the running firmware version**. |
| `rekit.symbols` | Find printable Orbis-style `sce*`/`libSce*` names and candidate encoded NID strings, retaining offsets | Strings are only **heuristic candidates**, not confirmed imports or function symbols. No arbitrary string dump. |
| `rekit.netmap` | Build five-second event timelines from sanitized TShark summaries already generated by `psn_netdiag` | Metadata cannot reveal encrypted TLS contents, PSN login outcome or where firmware checks run. |

## CLI examples (Windows PowerShell, project root)

Inspect an ELF already built in the project:

```powershell
python -m host.ps4_sender.rekit binary .\dist\firmware_info.elf
```

Extract names useful for investigation in Ghidra:

```powershell
python -m host.ps4_sender.rekit symbols .\dist\firmware_info.elf
```

Inspect a *raw* `PARAM.SFO` that you have permission to analyze:

```powershell
python -m host.ps4_sender.rekit psf .\samples\param.sfo
```

Create a timeline from an existing anonymized metadata file:

```powershell
python -m host.ps4_sender.rekit net .\gw_psn_attempt.json
python -m host.ps4_sender.rekit net-diff .\gw_baseline.json .\gw_psn_attempt.json
```

Use output redirection if a persistent report is needed:

```powershell
python -m host.ps4_sender.rekit symbols .\dist\firmware_info.elf > .\symbol_report.json
```

**Security and privacy:** never share raw PCAP, authentication tokens, account information, decrypted contents, or unreviewed binary reports publicly. Verify locally before publishing even bounded metadata. No files are uploaded by these commands.

## Actual local artifact observations

On the included `dist/firmware_info.elf`, the offline symbol scanner detects such strings as:

- `sceKernelGetSystemSwVersion`
- `libSceSystemService.sprx`
- `libSceNet.sprx`
- `libSceSsl.sprx`

These observations identify **potential API/library references in our own compiled test payload**, not a PSN version spoof or PSN authentication implementation.

## Suggested Ghidra workflow

1. Use `binary` and `symbols` to inventory local ELF files and collect SHA-256 evidence.
2. Import an **already decrypted and legally obtained** ELF into Ghidra as `x86:LE:64` and confirm the imported header.
3. Use the exported names and offsets as hints; verify the actual code references in Ghidra before adding comments or function signatures.
4. Record findings separately as **observed / inferred / unverified**; document source file hashes and tool versions.
5. Compare network metadata using `net-diff` only after collecting actual gateway-visible events. A capture with no relevant traffic cannot establish local vs remote checks.
